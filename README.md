One sentence on a small moment of wonder in everyday life: at a red light, forty strangers tilt their heads to the same slow cloud, and for eight seconds the city has exactly one thought. The program writes that single line to /output/entry.txt for the make.fun judge to compare pairwise.

## Run it

```sh
python3 main.py
```
